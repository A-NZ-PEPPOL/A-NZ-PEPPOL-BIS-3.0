# A-NZ PEPPOL BIS

**This repository has been retired.** The A-NZ extension of the Peppol BIS Billing 3.0 specification was deprecated on **22 May 2025** and was removed from the Peppol network as of **31 March 2026**. It is no longer supported, and the specification artefacts, schematron validation files, and message examples that were previously hosted here have been removed from this repository.

This README remains in place solely to direct users to the current specifications.

## What replaced A-NZ BIS Billing 3.0?

eInvoicing in Australia and New Zealand is now supported by the **PINT A-NZ Billing & Self-billing specifications**, published by OpenPeppol. PINT A-NZ Billing is the mandatory specification for eInvoicing in Australia and New Zealand and has been since 15 May 2025.

For the current specifications, implementation guidance, and technical artefacts, see:

* [PINT A-NZ Specifications (OpenPeppol)](https://docs.peppol.eu/poac/aunz/)

Peppol Service Providers and other implementers should refer to the OpenPeppol documentation above for all current schematron validation rules, code lists, and message examples — this repository will not be updated further.

## Procure to Pay (Peppol eProcurement)

Other Peppol eProcurement documents (Invoice Response, Catalogue, Punch Out, Order, Despatch Advice, etc.) are unaffected by this change and do not require localisation for use in Australia and New Zealand.

Current Peppol eProcurement specifications and technical artefacts are available [here](https://docs.peppol.eu/poacc/upgrade-3/).
